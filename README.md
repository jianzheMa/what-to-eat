# 今天吃什么

一个移动优先的附近餐厅随机推荐工具。适合饭点选择困难时快速决定去哪吃，支持定位、筛选、加权随机推荐、收藏、拉黑、历史记录、分享和一键导航。

## 功能亮点

- 基于高德地图定位搜索附近餐厅
- 支持最低评分、最远距离、人均价格、菜系偏好筛选
- 支持“今天不想吃”负向筛选，例如不要太辣、不想太远、不想太贵
- 使用加权随机推荐，综合评分、距离、预算、收藏口味和最近吃过记录
- 推荐结果展示推荐理由，减少纯随机的不确定感
- 支持一次显示 1-3 家餐厅
- 支持收藏“想去”、拉黑、最近记录和分享
- 支持摇一摇手机随机选一家
- 支持高德地图导航和结果小地图

## 本地运行

项目是原生 HTML/CSS/JavaScript，不需要安装依赖。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:4173/index.html
```

## 高德地图配置

首次使用需要在页面里填写高德地图 Web 端 JS API 的 `API Key` 和 `securityJsCode`。

申请地址：

```text
https://console.amap.com/
```

创建应用时选择 Web 端 JS API。保存后页面会重新加载并开始定位。

## 数据存储

当前版本使用浏览器 `localStorage` 保存：

- 高德地图 API 配置
- 筛选设置
- 最近记录
- 黑名单
- 想去收藏

这些数据只保存在当前浏览器中，不会同步到云端。
